# Предсказываем broadcasting shape

Реализуйте `broadcast_add(a, b)` обычным сложением тензоров. Перед запуском тестов **вручную предскажите** формы результатов для нескольких входов.

Ключевое правило: размерности сравниваются справа налево. Размеры совместимы, если равны или один из них равен 1; отсутствующие ведущие размерности можно мысленно считать равными 1.
