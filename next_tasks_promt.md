### 09_memory_and_views

#### 01_slice_is_view

Задача должна показать, что обычный slice часто является view исходного tensor.

Например:

```python
x = torch.arange(...).reshape(...)
part = x[:, 1:3]
```

После изменения `part` должен изменяться `x`.

Ученик должен явно столкнуться с тем, что Tensor не обязательно владеет отдельной памятью.

---

#### 02_clone

Продолжение предыдущей задачи.

Нужно сравнить:

```python
view = x[:, ...]
copy = x[:, ...].clone()
```

Изменение `view` должно менять исходник, изменение `copy` — нет.

---

#### 03_strides_and_contiguous

Познакомить с:

```python
Tensor.stride()
Tensor.is_contiguous()
permute()
contiguous()
view()
reshape()
```

Например:

```python
x = torch.arange(12).reshape(3, 4)
y = x.permute(1, 0)
```

Нужно показать:

* почему `y` становится non-contiguous;
* что данные физически не переставились;
* что изменились strides;
* почему `view()` может не работать;
* почему `reshape()` иногда способен выполнить ту же операцию;
* зачем нужен `contiguous()`.

Не требуй глубокого знания внутреннего устройства PyTorch, но после задачи человек должен понимать идею strides.

---

#### 04_expand_vs_repeat

Сравнить:

```python
expand()
repeat()
```

Нужно показать, что `expand` обычно не копирует данные и может использовать stride 0, а `repeat` создаёт повторённые данные.

Задача должна также закреплять связь `expand` с broadcasting.

### 10_advanced_broadcasting

Это один из важнейших разделов.

#### 01_predict_shapes

Сделай задачу/мини-набор примеров, где ученик должен получить или проверить формы результатов broadcasting.

Используй не только 2D tensors.

Обязательно должны встретиться случаи вроде:

```text
(3, 1, 5)
(1, 4, 1)
→ (3, 4, 5)
```

и случаи, когда количество размерностей различается:

```text
(8, 3, 1)
(1, 5)
→ (8, 3, 5)
```

Нужно закрепить правило:

broadcasting сравнивает размерности справа налево, а отсутствующие ведущие размерности можно мысленно считать равными 1.

Желательно, чтобы часть задания требовала не просто выполнить операцию, а осознанно построить tensors нужной формы.

---

#### 02_pairwise_differences

Практическая задача.

Дано:

```python
points.shape == [N, D]
queries.shape == [M, D]
```

Нужно получить:

```python
delta.shape == [N, M, D]
```

где:

```python
delta[n, m] = points[n] - queries[m]
```

Без Python loops.

Использовать `unsqueeze` и broadcasting.

Это очень важная задача.

---

#### 03_broadcast_middle_axis

Сделай задачу, где единичную размерность нужно вставить не только в начало или конец, а осознанно выбрать место.

Например нужно совместить tensors форм:

```text
[N, C]
[N, T, C]
```

или аналогичный понятный пример.

Цель — научиться выбирать правильный `unsqueeze(dim)`.

---

#### 04_broadcasting_errors

Добавь небольшую задачу, где некоторые shapes несовместимы.

Ученик должен понять, почему, например, определённые размеры нельзя broadcast.

Не нужно ловить исключения ради исключений — важна именно модель совместимости размерностей.

#### 02_gather

Отдельная полноценная задача на `torch.gather`.

Например:

```python
x = tensor([
    [10, 11, 12],
    [20, 21, 22],
    [30, 31, 32],
])

indices = tensor([2, 0, 1])
```

Получить:

```python
tensor([12, 20, 31])
```

То есть для каждой строки выбирается свой столбец.

Нужно заставить ученика разобраться с:

* `dim`;
* shape tensor'а индексов;
* необходимостью `unsqueeze`, если она возникает.

---

#### 03_scatter

Сделай логическое продолжение `gather`.

Нужно разместить значения по разным позициям результирующего tensor через `scatter` или `scatter_`.

Задача должна показать идею:

`gather` читает по индексам, `scatter` записывает по индексам.

---

Например кусочно заданное преобразование значений.

