# Пакет диагональных матриц

## Задание

Реализуйте `batched_diagonal(values, offset=0)`. Входной тензор имеет форму
`[..., N]`: последняя ось содержит диагонали, а все предыдущие оси считаются
пакетными. Одним вызовом `torch.diag_embed` превратите их в пакет матриц и
верните результат.

Проверьте, как `offset` меняет размер двух последних осей. Не используйте
Python-циклы и не вызывайте `torch.diag` отдельно для каждого элемента пакета.
