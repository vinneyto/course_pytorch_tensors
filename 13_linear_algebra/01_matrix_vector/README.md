# Матрица на вектор

## Задание

Реализуйте `matrix_vector(a, x)` для `a: [3,3]`, `x: [3]` с помощью `@` или `torch.matmul`. Результат имеет форму `[3]`; не пишите циклы.

## Материалы

- [`torch.matmul`](https://docs.pytorch.org/docs/stable/generated/torch.matmul.html)
