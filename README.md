# Практикум: тензоры PyTorch

Небольшой курс для знакомства именно с **API тензоров**, без нейросетей и
машинного обучения. Материал рассчитан на новичка: задания идут от создания
тензора до сохранения данных и воспроизводимой генерации случайных чисел.

## Как устроен курс

Корневые пронумерованные каталоги — темы. В каждой теме находятся
пронумерованные задания. Каждое задание содержит:

- `README.md` — условие и подсказки;
- `task.py` — заготовку, которую нужно дополнить;
- `test_task.py` — исполняемую спецификацию решения.

Проходите темы по порядку. Не изменяйте тесты: меняйте только `task.py`.

## Подготовка окружения

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

```bash
uv venv
uv sync --dev
```

`uv sync` создаёт `.venv`, если окружение ещё не создано. Активировать его
необязательно: `uv run` сам выберет окружение проекта.

## Запуск задания

Перейдите в каталог задания и запустите тест:

```bash
cd 01_creation/01_from_data
uv run pytest test_task.py
```

Сначала тест ожидаемо падает с `NotImplementedError`. Реализуйте функции из
`task.py` и повторяйте запуск, пока тест не станет зелёным. Для подробного
вывода используйте `uv run pytest -vv test_task.py`.

Проверить синтаксис всех заготовок и целостность структуры курса можно из
корня (решать задания для этого не нужно):

```bash
uv run python scripts/check_course.py
```

## Темы

1. `01_creation` — создание тензоров.
2. `02_shape_and_views` — форма, представления и перестановка осей.
3. `03_indexing` — срезы, маски и выбор элементов.
4. `04_math_and_broadcasting` — поэлементные операции и broadcasting.
5. `05_reductions` — агрегации и работа с осями.
6. `06_dtype_and_device` — типы данных и устройства.
7. `07_combine_and_split` — объединение и разбиение тензоров.
8. `08_random_and_io` — случайные числа, сохранение и загрузка.

## Правила выполнения

- Не преобразовывайте тензоры в списки или NumPy, если это прямо не разрешено.
- Не зашивайте ожидаемые значения: функции должны работать с любыми входами
  подходящей формы.
- Обращайте внимание на `shape`, `dtype`, `device` и на то, создаётся копия
  или представление исходных данных.
- Полезно сверяться с документацией через `help(torch.Tensor.reshape)` и
  `help(torch.cat)` прямо в Python.
